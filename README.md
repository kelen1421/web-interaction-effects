## 安装与调用

将仓库内的 `skills/web-interaction-spec` 文件夹放入你的 Codex 技能目录，默认位置为 `~/.codex/skills/web-interaction-spec`。如果已有同名技能，更新前先保留自己的修改。

调用名称：`$web-interaction-spec`。

示例请求：

> 使用 $web-interaction-spec，先给我看全部效果和预览，再帮我为作品集选择合适的卡片悬停效果。

> 使用 $web-interaction-spec，在当前项目中实现 H08 方向感知悬停，并提供触摸和键盘的等效操作。

> 使用 $web-interaction-spec，实现 P04：临界阻尼弹簧、继承松手速度，并在左右边界单独加入回弹。

已有明确目标和实施要求时，技能会在展示预览后继续实施。仅要求认识或整理效果时，不修改项目。

## 更新预览

`skills/web-interaction-spec/assets/preview.html` 是预览的单一来源。修改后，用 Python 3 重新生成独立页面与聊天预览片段：

```sh
python3 skills/web-interaction-spec/scripts/prepare_preview.py \
  --output-dir preview \
  --fragment-dir work/preview-fragment
```

生成器仅依赖 Python 标准库；预览无外部字体、图片、脚本或网络请求依赖。
可追加 `--initial-effect P04`，让本次预览从边界回弹开始，完整目录仍保持可见。

更新独立预览后，运行 `python3 build_pages.py` 同步公开网页入口 `index.html`。GitHub Pages 使用 `main` 分支根目录；提交更新后自动发布。网页保留完整目录，新增导航、需求复制和效果链接；原始教学预览保持独立。
