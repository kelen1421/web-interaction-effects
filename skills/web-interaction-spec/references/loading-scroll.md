# 加载与滚动

来源：JIEJOE_轻敲代码《你应该知道的网页交互术语 01》，https://www.bilibili.com/video/BV1UEaq6qEZt/ 。2026-11-09 读取页面、165 条 AI 字幕（0.04–298.90 秒）、部分画面及作者置顶补充。以下是提炼与校正，不是逐字稿。

## 术语与行为

| 视频时间 | 概念 | 实施时说明什么 |
| --- | --- | --- |
| 00:24–01:02 | Loading / Loader；Splash；页面 Transition | 首次展示的范围、真实就绪条件、站内切换是否重播；不把 Splash 强制设为每次导航都出现 |
| 01:02–01:16 | 遮罩式转场 | 遮挡→替换内容→揭开；交代中断与失败后的恢复 |
| 01:16–01:26 | 交叠式转场 | 旧页退出、新页进入的重叠时段；防止两页同时响应点击 |
| 01:26–01:48 | 共享元素转场 | 明确同一视觉对象的两端位置/尺寸；不假设必须是同一个 DOM 节点 |
| 01:48–02:13 | 入场动画；Hero Section | 主视觉区是区域概念，入场是它出现的过程；不是每个网站都需要加载动画 |
| 02:13–02:33 | Smooth Scrolling；Lenis | 平滑的是滚动手感，独立于动画是否滚动驱动 |
| 02:33–02:51 | 滚动触发 | 达到阈值后启动按时间播放的过程；停滚不一定停动画 |
| 02:51–03:10 | 分段式滚动 | 按段切换的规则、输入阈值和连续输入处理；不能只凭无滚动条判断 |
| 03:10–03:24 | 单次触发 | 播放一次后保留终态 |
| 03:24–03:40 | 视频称“单向可逆” | 示例是向上回到触发区域之前后重置，再向下可重播；不等于连续倒放 |
| 03:40–03:50 | 双向重置 | 从任一方向离开范围后重置，再次进入可触发 |
| 03:50–04:42 | 滚动驱动 | 滚动位置映射动画进度，能前进/回退；可即时对应或平滑追赶 |
| 04:03–04:31 | 文字显现、裁剪展开、视频帧、横向位移、摄像机、模型、场景 | 明确输入区间和各阶段状态；这些是驱动对象，不是不同输入机制 |
| 04:31–04:42 | 视差位移 | 前后层不同速率相对移动；可横向或竖向 |

## 不要继承成硬性规范

- 作者置顶说明：不少术语来自从业者描述，不是唯一名称或统一标准。
- 遮罩/交叠/共享元素的稳定性比较是作者经验，不是必然排序；“更丝滑”“更有效”不等于实测指标。
- 未获得留存率、性能、兼容性等实验数据，不编造百分比或最佳时长。
- 案例网站未逐一确认来源、依赖和源码，不宣称已复刻其实现。
- AI 字幕的 LINUX 已按画面与评论校正为 Lenis；hero session 校正为 Hero Section；TRANSSESSION 等校正为 Transition。

## 实现参考

具体实现时再查当前文档：
- Lenis：https://lenis.dev/ ，平滑滚动工具，不自动创建所有滚动动画。
- GSAP ScrollTrigger：https://gsap.com/docs/v3/Plugins/ScrollTrigger/ ，事件触发、scrub、pin、snap；视频末尾画面展示其文档。
- View Transition API：https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API ，补充的实现选项，非视频证明每个案例都用了此 API。
