# 展示预览

技能自带 `assets/preview.html`（完整目录和互动舞台的单文件片段）。目录中的编号用于选择，不代表标准术语编号。

## 每次调用

1. 运行 `python3 <skill>/scripts/prepare_preview.py --output-dir <当前任务的outputs目录> --fragment-dir <当前聊天允许的visualizations目录或work目录>`。脚本复制片段并生成不依赖外部资源的完整预览页；所有路径使用实际绝对路径。
2. 支持聊天内交互预览时，在本轮最终回复中使用 `visualize{"path":"<脚本返回的fragment路径>"}`。不能只给一个代码文件链接代替可见预览。全目录在预览下方，点名称即可切换舞台；无需加载外部字体、库或图片。
3. 可通过宿主的打开浏览器功能把生成的完整预览页显示在旁边，尤其是在还要继续实现、不能等最终回复才展示时。使用当前允许的浏览器控制方式，确认能显示后再称已打开；若 file URL 受限，可用只监听127.0.0.1的本地静态服务。
4. 不支持聊天预览时，提供完整HTML页并尝试在可用浏览器打开。无法打开时如实说明限制，仍列出已收录目录和可打开文件。不要把“文件生成”说成“已在用户界面展示”。

## 操作与范围

- 加载/转场类：点击“播放演示”。预览时间和几何形状只用于说明原理，加载进度明确为模拟。
- 滚动类：拖动“滚动进度（模拟）”，观察触发阈值、重置、连续驱动；这不是接管真实页面滚轮。
- 悬停类：把指针移入/移出舞台中的目标；也提供“模拟移入/移出”按钮方便触屏与键盘使用。方向感知可以实际从不同边进入，方向按钮用于无鼠标设备。
- 预览支持“减少动态效果”；所有目录和信息持续可读。
- 28项涵盖两期已确认的主要类型与代表性变化，包含一个明确标注的坐标揭示教学扩展。三维/视频帧相关项为自制几何示意，不是原案例录像或真实3D资产。

## 修改预览时

编辑 `assets/preview.html` 的目录数据和渲染逻辑，再运行生成脚本。维护单一来源，不手工改输出副本。每个目录条目都要有对应演示；核对全部编号唯一、选择后舞台更新、键盘可操作、320px宽度可读。
