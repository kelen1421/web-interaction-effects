# 弹簧动画、阻尼与拖拽释放

## 来源边界

用户补充的静态截图写有“弹簧动画（spring）、阻尼比设成1、带上松手速度、到边界加回弹”。没有提供原视频链接、作者或完整上下文。只能核实截图文字，不能确认实际运动、所用框架或参数。本模块是据此制作的教学实现，独立于此前两期视频。

## 四个概念

- **P01 弹簧动画**：位置与速度由弹簧力、阻尼共同演化。动画中断并重新抓取时，应从当前状态接续，而不是回到固定起点。
- **P02 阻尼比 ζ=1**：临界阻尼；从静止偏离平衡位置释放时不来回振荡。ζ<1 为欠阻尼，ζ>1 为过阻尼。非零初速度可能改变是否穿过目标，不能一概承诺任何初态都不越过目标。
- **P03 松手速度**：释放瞬间的位置变化率，决定弹簧的初始速度及方向。不要仅根据拖动总距离估算，更不能在每次松手时套同一个固定速度。长时间停住再松手应近似为零。
- **P04 边界回弹**：描述到达允许范围边缘后的规则。可以用边界弹簧、橡皮筋式越界回收或碰撞反射；先说明所选模型。本预览选择硬边界碰撞：把位置限制在边界，并令向外速度按 `v_after=-0.55*v_before` 反向衰减，随后继续向目标的弹簧运动。

“阻尼比为1”与“边界回弹”可组合，但后者来自额外的边界规则，并非临界阻尼自动产生来回振荡。

## 参数映射

对质量 m、刚度 k、阻尼系数 c 的线性弹簧：

`ζ = c / (2 * sqrt(k*m))`，因此 `c = 2 * ζ * sqrt(k*m)`。

例如 m=1、k=64、ζ=1，对应 c=16；不是 c=1。若框架直接提供 `dampingRatio` 或 `ratio` 可按其文档设置；只有 `damping` 字段时，先确认该字段的含义。

Motion 的物理弹簧通过 stiffness、damping、mass 配置，并可继承速度；仅配置 duration/bounce 的弹簧不等价于保留真实松手速度。边界配置也需要单独指定，不能只设置 bounce 就声称已建立边界。

## 描述模板

> 对目标元素使用物理弹簧动画，阻尼比 ζ=1；拖动时跟随指针，松手时以当前的位置和采样速度继续运动。明确左右边界，到达边界后按约定的边界回弹模型响应并逐渐停稳。允许运动中重新抓取；取消手势时不制造额外甩动。为触摸、键盘和减少动态效果提供等效操作。

## 预览与验收

预览以轨道长度为单位，真实手势由像素位移换算；速度截断到 ±4 轨道/秒用于稳定演示，接入实际产品时另行决定限速。使用最近120毫秒采样，长停后释放不继承陈旧速度。自然频率取8，默认质量1/刚度64；这些是自制参数。

检查零初速度的临界阻尼是否单调收敛、欠阻尼是否越过目标、松手速度开关是否改变轨迹、两侧碰撞是否留在边界内并损失能量。检查快速重播、运动中重新抓取、指针取消、窗口缩放、键盘操作及减少动态效果。位置与速度同时低于阈值才停稳。
