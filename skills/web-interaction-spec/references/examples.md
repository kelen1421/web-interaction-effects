# 需求描述示例

下列数值为教学示例和可调整默认值，不是原视频的测量结果。

## “卡片滚到这里才出现，再滚回来别重新播”

术语：一次性滚动触发入场。卡片进入视口后，从下移24px、透明度0过渡到原位、透明度1；触发后独立完成，向上滚动不倒放，再次进入不重播。减少动态效果时直接显示。验收：下滑首次出现→返回→再次下滑，动画只发生一次。

## “图片随滚动慢慢放大，往上滚就缩回”

术语：滚动驱动缩放。明确目标滚动区间；以该区间进度控制图片从原大小到目标大小。停止滚动时停在对应状态；反向滚动回退。时长不应写成固定2秒；可选是否带追赶延迟。验收：停在25%、50%、75%，状态不同且可往返。

## “移上去出现项目说明”

术语：Hover Reveal。指针进入卡片时揭示标题/简介，离开恢复；键盘聚焦也能查看。触摸可以常驻简介或用明确展开按钮，不吞掉原有导航点击。验收关注信息能否读到，不只看透明度动没动。

## “鼠标进入喷一下，移出去不要倒回去”

术语：指针移入触发的一次性粒子动画。进入时启动，启动后即使离开也继续完成；说明再次进入能否重播、快速连入是否合并或替换。不要用移出状态直接把时间轴倒放。预览使用几何粒子表达喷溅原理。

## “按钮色块左进右出”

术语：非对称悬停过渡。进入时色块由左到中，离开时由中到右，而不是左边退回。快速再次进入时先取消旧动画，从当前状态或明确初态继续；文字和实际点击区域不变。键盘焦点使用相同状态规则，触摸保留正常点击。

## “从哪边移入，就从哪边染色”

术语：方向感知悬停。计算指针相对卡片边界的进入边，遮罩从对应边进入；离开时按离开边退出。角落采用一致的最近边规则，键盘使用固定方向。验收分别从四边进入、从另一边离开，不能永远左进右出。

## “把这两张页面用同一张封面连起来”

术语：共享元素转场。指定封面在旧页/新页的范围，其他内容分别进退。确认点击中断、返回导航、资源失败仍能显示目标页；不把“共享”解释成必须共享某一实际节点。未给项目时只交需求说明，不修改任意历史项目。
