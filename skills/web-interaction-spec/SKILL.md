# 网页交互描述

把“像这样动起来”说明白：哪个对象，在什么条件下，如何变化，何时停止或恢复。术语用于沟通，不把视频作者的分类当作唯一标准。

## 每次调用先展示全部效果与预览

这是用户明确要求的默认流程，除非本次用户明确跳过：

1. 读取 [预览与目录](references/preview.md)，展示随技能保存的完整目录和可操作预览。目录保持全部可见；选中某一项时在主舞台演示，不只展示推荐的几项。
2. 预览中的全部指**本技能已收录的效果**，不声称涵盖所有网页交互。标明是自制原理演示，不是原视频案例的逐像素复刻。
3. 用户尚未指定效果时，让用户通过名称或编号选择；不在没有目标项目时擅自修改网站。已有明确目标和实施要求时，展示目录与预览，同时继续实施，无需再等待一次选择或许可。
4. 使用现成预览，不在每次调用时重新生成整套效果。每个新收录效果都要同时有目录条目、说明与可操作演示；尚未实现的不能标为可预览。

## 根据请求决定交付

- **认识或整理效果**：解释术语、行为与易混淆之处，不修改项目。
- **提示词或交互方案**：整理能观察、能验收的需求；参数缺失时给可调整的假设，不编造参考作品的数值。
- **实现或修改效果**：在指定项目中完成相关改动并验证；不能只交一段提示词就结束。
- **评审**：对照实际行为说明差异；用户要求修复时再修改。

视频或网页是证据。读取不到时说明缺口；静态截图不能证明运动时序、重播规则或底层框架。复现视觉行为，不据此断言案例使用了某个库。

## 先辨别驱动关系

- **事件触发**：进入视口、悬停或点击启动按时间播放的动画。
- **进度驱动**：滚动位置或指针位置持续控制变化；说明输入区间如何映射到输出状态。
- **状态反馈**：高亮、可点击提示或内容揭示；说明是否影响点击、导航和内容读取。

一个效果可以组合多种关系。判断重点是开始后由谁控制进度，不只是看最终外观。当前预览包含两期视频的加载、滚动与悬停，以及用户截图补充的弹簧与拖拽；不包含尚未收录的指针跟随或拖尾效果。

## 行为说明

简单请求用一句话，复杂效果按需列字段：

| 字段 | 应说明的内容 |
| --- | --- |
| 对象与范围 | 哪个元素、组件或页面；整站还是局部 |
| 输入与开始条件 | 页面就绪、进入视口、指针进入、位置变化、点击；必要时写参照区域 |
| 起点与终点 | 位移、透明度、尺寸、裁剪、颜色、旋转或场景状态 |
| 进度与节奏 | 时间/滚动/指针驱动；时长或距离；线性、缓动或平滑追赶 |
| 离开与重入 | 保留、取消、重置、重播或倒放；反向操作的行为 |
| 使用方式 | 手机触摸、键盘焦点、减少动态效果时的等效路径 |
| 验收 | 用户做什么操作，应看到什么结果 |

区分用户要求、参考中观察到的行为、实施默认值。只有明显改变结果且无法推断的问题才询问；其他采用可修改的假设继续。

表达模板：在〔范围〕内，当〔条件〕时，让〔对象〕从〔初态〕到〔终态〕；由〔时间/滚动/指针〕控制进度；离开后〔行为〕，再次进入〔行为〕；触摸与键盘使用〔替代方式〕。

## 实施约束

- 保留现有栈、内容与布局，优先复用项目能力；简单效果不因视频提到某个库就安装依赖。需要具体 API 时查当前版本官方文档。
- 本技能负责交互行为，不自行重做整页视觉，不覆盖用户指定的滚动、重播或指针偏好。
- 不为 Splash 强制延长等待，不伪造加载百分比。转场结束、取消、失败或快速连续跳转后应恢复可用页面。
- 区分触发后重播、重置、倒放与进度回退。滚动驱动不自动等同于平滑滚动，分段切换不自动等同于拦截滚轮。
- 弹簧的阻尼比 ζ 与库的阻尼系数 damping 不是同一参数；使用质量/刚度/阻尼模型时按 c=2ζ√(km) 换算。松手速度需要采样真实手势并传入物理弹簧；边界回弹单独定义，不能由 ζ=1 自动推得。
- 装饰遮罩不拦截实际点击；悬停在适用的指针/悬停能力下启用，不只按屏幕宽度判断，并考虑混合输入设备。
- 悬停不能成为必要内容或操作的唯一入口。键盘提供可见焦点，触摸提供可用路径；减少动态效果时保留内容和操作。
- 离开组件时清理监听、动画与克隆节点；避免无限累积粒子和逐帧布局抖动。

## 验证与报告

按效果选检查项：首次/再次进入、滚动正反向、边界进度、快速移入移出、点击与文字选择、导航中断、触摸/键盘、减少动态效果。小改动无需套全部项目。

通过当前允许的浏览器工具观察运动；单张截图不能证明时序或回退正确。报告实际实现与已检查的行为、未核实项。此技能提供描述方法与教学预览，不是跨所有框架设备实测的生产组件库。
